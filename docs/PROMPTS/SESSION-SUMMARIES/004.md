## Summary

The build-it session. Blaine gave point ("build until completion, full qa audits, ensure
demo is playable") and the nine-task turn-structure v2.0 plan was executed start to finish
under superpowers:executing-plans — rounds + claimable initiative replacing per-player turns,
summoning sickness gone (units enter ready; Rush = exhaust-free entry-round move), and
single-attacker combat replaced by multi-unit attack + a defender intercept window. The
engine (tasks 1–6) was driven directly, TDD throughout, committing per task with the suite
green each time; the two UI surfaces (task 7 demo, task 8 web+server) went to parallel
subagents against a shared behavioral contract, then were reconciled and verified.

Three plan wrinkles were caught and handled rather than copied blind: two test code-blocks
that contradicted their own design notes (round hand-count `7+2`→`7`; granted-Rush-on-veterans
pinned to the strict "still exhausts" reading, flagged as a designer question); and the fact
that `npm test` also runs the server suite (whose scripted game drove the old phase flow) —
so engine tasks gated on the engine suite and the server tests were brought green in task 8.
Several intercept-era test fixtures had to be reworked where the plan's assertions would have
read a unit that dies in combat (a guard soaking a base hit, an overextending loner eating a
lethal counter, a ranged group killing its target).

The parallel subagents nearly collided on the shared `@ui` components (the demo renders
files that physically live under `apps/web/src/game`) — the web agent noticed the concurrent
worker and deliberately deferred to the demo's versions, so nothing clobbered. A sweep then
fixed remaining v1 player-facing copy the agents flagged: the HelpPanel (taught v1 turns,
summoning sickness, guard-forced-targeting), the keyword gloss (guard/overextend), and the
BaseSheet's "guards must be attacked first."

Verification was thorough: full 4-package typecheck clean, 99 tests green, card CSV valid,
and the demo **browser-driven through a full 6-round vs-AI game** — bank steps, action loop,
multi-unit combat, three human-answered intercept windows, natural winner, zero page errors;
plus sim→replay faithfulness and no mobile overflow. Sim baselines moved as decision 44
predicted: **first-mover advantage is gone (seat-0 wins 50%)**, red aggression rose
(heuristic mirror ~30%→~45%, ~96% by Life), influence upsets stayed rare (~4–6%).

Landed as a clean version boundary: tagged **v0.1** at the pre-rework main (v1.2-rules
prototype) as a restore point, fast-forward merged v2.0 into main, tagged **v0.2**. All local.

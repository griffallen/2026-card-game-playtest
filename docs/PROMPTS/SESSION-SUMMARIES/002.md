# Session 002

**Date:** 2026-07-08
**Working with:** builder (designer participating via relayed spreadsheet notes — his first design review)
**Phase:** Playtest & iterate — four human playtests, one designer session, decisions 31–39

## Summary

The night the loop started looping. Blaine played four real games against the baseline AI and every
loss taught the product something: game 001 ended by his own Final Onslaught at −14 influence (→
lethal-play warning, contextual hints, auto-pass, How-to-play panel); game 002 exposed the
imprisoned-units-as-influence-food interaction and the telegraphed-march problem; game 003's screenshot
round produced the full UX audit (tap-to-inspect on everything, event ticker narrating the board, pile
browsers, mobile action dock, base stat block, long-press details); game 004 falsified a card ruling
live — Crimson Behemoth's splash only ever hit an empty Neutral — and got re-ruled the same hour. The
demo grew a Deck Explorer, replay transport (pause/step-both-ways/speed, Watch▶ links from simulator
rows, proven move-for-move faithful), and hand sorting with type chips.

Then the designer's notes arrived. He ratified movement ("a barrier for aggressive decks"), corrected
Overextend to his real design (optional attack gamble: +N power now, N self-damage at end of turn — the
influence-cede reading was an artifact and is gone), demanded influence never be passive (guards now pay
when they *defend*, Exemplar when it kills — entry income deleted), added mulligans (unlimited, one
fewer card each) and an empty-deck penalty (−1 life/−1 influence per missing card), put prison "on
notice," asked for a multi-unit-attack + defender-interception combat system (drafted as decision 38,
**paused at the builder's direction until the turn-structure rework**), and asked for a better name than
"base/home" (Banner/Hearth/Seat/Beacon offered). Decision 31 — players choose their two starting banks
— had already gone through the full loop earlier the same day, the project's first rules change born
from play.

The economy flipped exactly as hoped: sims went from influence-dominated (random mirror: red 1%, 130
influence wins) to combat-dominated (red 29–30%, influence wins 3/60 under competent play). The
event-trigger values are now the designer's tuning dial — and he can turn it himself: `data/cards.csv`
is the whole pool in one GitHub/Sheets-editable file (including an `influenceTrigger` column), with
import validation that rejects anything the engine can't execute. A colors roadmap maps green/blue/
purple onto the engine's existing vocabulary. All cards acknowledged as AI-drafts to be normalized.

## Decisions

31. Setup banks are chosen by players (first rules change from play) — builder.
32. Unlimited mulligans, one fewer card each — designer.
33. Empty-deck draws cost 1 life + 1 influence each — designer.
34. Influence is event-earned only (onDefend/onKill/onPlay per card; no passive income) — designer.
35. Overextend = optional attack gamble, +N now / N self-damage at end of turn; action-printed OE inert pending card pass — designer.
36. Movement/exhaust-march ratified — designer.
37. Prison kept but "on notice" — designer.
38. Multi-unit combat + defender interception: drafted, paused for turn rework — builder.
39. All 84 cards are AI-drafts; CSV workflow + engine validation is the normalization path.
(Also this session: Crimson Behemoth splash re-ruled from playtest 004; response windows named and
auto-passed; granted-Rush-on-veterans flagged as a designer question.)
